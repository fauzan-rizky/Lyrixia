# Lyrixia

**Lyrixia** is a Python-based tool designed to convert lyric JSON files from *word-level* and *lyric-blocks* formats into a simpler JSON structure, ready to be used by a lyric renderer.

## Usage

### Convert

Run the following command in your terminal:

```bash
python lyric_json_converter.py "file_blocks.json" "file_wordlevel.json" -o "hasil.json"
```
### Running

Create venv and enter venv

Install the 'requirements.txt' using ```pip3 install -r requirements.txt```
